# Hi, I'm Tarek

I'm a software engineer in Cairo, and a talented learner: I pick things up fast and I like using them straight away. I just make stuff. The last few years have been Python, Flutter, TypeScript and ML, plus a lot of backend and some embedded C and C++. Most recently I picked up Rust, and a couple of months in it's already behind a few of my projects.

## What I do

- **AI and ML:** explainable fraud detection (XGBoost, SHAP and Gemini explanations), image captioning, NLP, and a phoneme-level speech scorer for kids learning Egyptian Arabic.
- **Backend:** FastAPI, Supabase, Docker and Azure. I've built auth, calendar and messaging services during internships at Jiffy and Aispeak.
- **Mobile:** Flutter and Kotlin. I've shipped apps with Riverpod, Firebase and BLE, and an ESP32 band that predicts glucose on-device with TensorFlow Lite.
- **Systems and embedded:** C and C++ on microcontrollers like the ATmega, where you manage memory by hand, plus ESP32 firmware for Healthica. Rust is the newer addition, for desktop tools where a small, fast binary matters.
